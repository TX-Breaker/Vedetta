# Keyboard shortcuts

## Recordings

Single keys, no chords: usable with one hand. They work when the Recordings section is shown in the main window
and you are not typing in a text field. The same list opens with the keyboard button under the timeline (or **H**).

| Key | Action |
|---|---|
| Space / K | Play / Pause |
| ← → | Back / forward 10 seconds |
| ⇧ ← → | Back / forward 1 minute |
| ⌥ ← → | Back / forward 1 second |
| ↑ ↓ | Previous / next event |
| . | Next frame |
| + (or =) / – | Zoom the timeline in / out |
| 0 | Whole day |
| C | Center the timeline on the playhead |
| I / O | Selection start / end at the current time |
| E | Save on this Mac (the selection, if any) |
| S | Snapshot |
| 1 2 4 8 | Playback speed |
| Esc | Cancel the selection |
| H / ? | Show this list |

**Mouse only** — wheel over the timeline: zoom around the pointer; Shift + wheel: scroll (can be swapped in
Settings › Video › Recordings); click: jump to that time; buttons under the timeline: zoom −/+, move ‹ ›,
center, Start here / End here.

## Whole app

| Shortcut | Action |
|---|---|
| ⌘N | Add device… |
| ⌘1 … ⌘6 | Live, Recordings, Events, Exports, Album, Devices |
| ⌥⌘T | Start / stop the automatic tour |
| ⌥⌘← / ⌥⌘→ | Previous / next page of the live grid |
| 1 … 9 (Live) | Select a tile |
| ⌘, | Settings |
| ⌘Q | Quit (recordings in progress are finalized first) |
